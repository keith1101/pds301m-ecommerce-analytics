## Mục PARTIAL / MISSING

- **Mục 10: 4 Python functions (PARTIAL)**
  - *Hiện trạng:* File `src/business_rules.py` chứa đúng 4 hàm độc lập theo thiết kế Issue #21 (`calculate_revenue`, `is_cancelled_invoice`, `order_month`, `assign_customer_segment`).
  - *Thiếu sót:* Dòng 2 trong `src/business_rules.py` sử dụng cú pháp import `from feature_engineering import assign_rfm_segment` thay vì relative import (`from .feature_engineering import ...`) hoặc package import (`from src.feature_engineering import ...`). Do đó, khi chạy kiểm tra chuẩn từ thư mục gốc repository bằng lệnh `python -c "from src.business_rules import calculate_revenue"` sẽ xảy ra lỗi `ModuleNotFoundError: No module named 'feature_engineering'`. Hàm chỉ có thể import được nếu môi trường thực thi đã tự đưa `src/` vào `sys.path`. Ngoài ra, chưa có test case tự động riêng trong `tests/` dành cho module `business_rules.py`. (Lưu ý: module `src/eda.py` cũng có 4 hàm phân tích doanh thu `total_revenue`, `revenue_by_month`, `revenue_by_country`, `top_products` và import từ root không bị lỗi).

- **Mục 11: list / dict / set / tuple (PARTIAL)**
  - *Hiện trạng:* Cả 4 cấu trúc dữ liệu nguyên bản của Python đều xuất hiện rải rác và được sử dụng trong codebase, đặc biệt là `src/feature_engineering.py` (sử dụng cả list, dict, set, tuple trong việc định nghĩa hằng số, validate cột, tính điểm phân vị và trả về metadata).
  - *Thiếu sót:* Trong repository hoàn toàn không có một notebook, script hoặc bài demo độc lập nào trình bày trực quan các thao tác với 4 cấu trúc dữ liệu này (như khởi tạo, truy xuất, biến đổi, thêm/sửa/xóa, ép kiểu giữa các tập hợp) để phục vụ chấm điểm tiêu chí cơ bản môn học PDS301m. Notebook `notebooks/05_python_oop_demo.ipynb` được tạo cho Issue #21 chỉ demo duy nhất class OOP `RetailDataProcessor` với 4 cell code ngắn, không có nội dung minh họa list/dict/set/tuple.
